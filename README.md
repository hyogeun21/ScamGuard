# ScamGuard 종합 통합 소스 v3 (1.2.0)

React + Vite + Phaser 3. 기준 해상도 1920×1080.
지금까지 합의한 메뉴, 조사, 메모장, 일시정지, 새 게임 초기화를 통합한 버전입니다.

## 처음 실행

1. ZIP 압축을 풉니다.
2. VSCode에서 `scamguard` 폴더를 엽니다. `package.json`이 보이는 폴더입니다.
3. VSCode 터미널에서 순서대로 실행합니다.

```bash
npm install
npm run dev
```

터미널에 나온 주소를 브라우저에서 엽니다. 파일 탐색기에서 index.html을 더블클릭하는 방식이 아닙니다.
Node.js 20.19 이상 또는 22.12 이상 환경을 권장합니다.

## 기존 Vite 프로젝트에 적용

기존 프로젝트를 먼저 백업합니다. 이 ZIP의 `src/`, `index.html`을 사용하고, 본인의 이미지를 `public/assets/`로 복사합니다.
기존에 제공한 `InvestigationScene.js`, `PopupScene`의 수정 코드는 중복 적용하지 않습니다. 현재는 `OverlayScene.js` 하나가 팝업과 조사창을 관리합니다.
별도의 React 플러그인 설정 없이 실행할 수 있게 JSX 파일에서 React를 명시적으로 가져옵니다.
기존 package.json을 유지하려면 React, ReactDOM, Phaser, Vite 의존성이 필요합니다.

```bash
npm install phaser react react-dom
npm install -D vite
```

## 파일 구성

- `src/App.jsx`: Phaser 생성/해제, 1920×1080, DOM 레이어, 씬 등록
- `src/game/config.js`: 에셋 파일명, 게임 버튼 좌표, 오브젝트 좌표/크기, 충돌 영역, 팝업 크기
- `src/game/scenes.js`: Boot/Main/Scenario/Room/End 씬, WASD/E/ESC, 충돌
- `src/game/OverlayScene.js`: 게임방법/종료/일시정지/메모장/스마트폰/전화기
- `src/game/overlay.css`: 조사창 간격, 여백, 글자 크기, 말풍선, 질문 항목, 스크롤
- `src/game/computerContent.js`: 4개 시나리오의 컴퓨터 화면/연결/본문 데이터
- `src/game/content.js`: 시나리오별 메시지/추가질문/답변/연락처 예시 데이터
- `src/game/state.js`: 새 게임 데이터, 최근접 대상 선택, 중복 기록 방지
- `ASSETS.md`: 전체 이미지 목록과 제작/배치 안내
- `PROJECT_SPEC.md`: 현재 확정 기획과 남은 범위
- `TESTING.md`: 검증 결과와 직접 확인 절차

## 에셋 연결

실제 이미지 파일은 제공받지 않아 포함하지 않았습니다. `public/assets/`에 ASSETS.md의 파일명을 맞춰 넣으세요.
없는 이미지는 임시 도형/텍스트로 대체됩니다. 개발자 콘솔에서 이미지 404가 보일 수 있으며 해당 파일을 넣으면 없어집니다.
전체 배경은 1920×1080, 버튼/오브젝트는 투명 PNG를 사용하세요. 과도한 투명 여백을 피하세요.
현재 좌표는 임시 배치입니다. 원본 이미지 크기만 바꿔 넣어도 배치는 자동 완성되지 않으므로 config.js 및 overlay.css에서 실제 디자인에 맞춰 조절해야 합니다.

## 조작

- WASD: 이동, 대각선 속도 동일
- E: 200px 이내 가장 가까운 오브젝트 하나 조사 (중복 입력 방지)
- ESC: 방에서는 일시정지, 열린 창에서는 창 전체 닫기, 시나리오 선택에서는 메인 복귀
- 스마트폰/전화기 뒤로가기: 조사 내부의 이전 단계
- 스마트폰/전화기 X: 전체 조사창 닫기
- 메모장: 한글/줄바꿈/드래그 선택/Ctrl+C/V/X/A 지원

## 새 게임 규칙

시나리오 선택 후 `게임 시작하기`를 누를 때 새 runData 객체로 교체합니다.
메모, 조사 기록, 요청 질문, 단서, 답변/평가, 위치가 초기화됩니다.
같은 플레이 중 메모장/조사창 닫기, 일시정지는 데이터를 유지합니다.
메인 복귀 후 과거 플레이를 이어하는 메뉴는 없습니다. 새로 시작하면 항상 초기화됩니다.
브라우저 새로고침 시 데이터는 사라집니다. localStorage와 서버 저장을 사용하지 않습니다.

## 종료

`게임종료하기`는 종료 화면을 보여줍니다. 탭을 강제로 닫지 않습니다.
선택 에셋 `game-end.png`를 넣으면 게임 종료 이미지를 표시합니다.

## 현재 범위

컴퓨터는 4개 시나리오별 조사 흐름을 제공합니다. 문은 판단 입력/확인/대기/오류 재시도/결과 화면을 제공합니다. 실제 AI 대신 표시된 테스트 평가가 기본입니다. 실제 콘텐츠/별도 단서수집/실제 AI·백엔드/애니메이션/사운드는 미포함입니다. 실제 평가 API의 프런트 어댑터와 요청/응답 계약은 포함됩니다.
공식 연락처와 메시지 내용은 모두 예시입니다. 실제 교육 콘텐츠로 교체해야 합니다.

## 확인 명령

```bash
npm test
npm run build
```

빌드 결과는 dist에 생성됩니다. Phaser 크기로 인한 Vite 청크 경고는 실패가 아닙니다.

## 컴퓨터 추가판 변경

- 채용: 4개 선택지 → 상세 → 뒤로가기.
- 재택부업: 일반 상세 3개 + 업무 목록 → 업무 내용.
- 투자: 금융회사/공시 상세 + 투자앱 → 항목 → 가상출금 결과 + 공식앱 → 항목.
- 숙소: 일반 상세 2개 + 검색 → 결과 → 문의 + 예약/결제 → 결제안내확인.
- 모든 컴퓨터 단계에 X/ESC 전체 닫기. 숙소 예약/결제안내에는 기획대로 뒤로가기 없음.
- 컴퓨터 방문 기록 computerPages도 새 게임마다 초기화.
- 상세 내용과 일부 선택지 제목은 예시이며 팀의 실제 콘텐츠로 교체 필요.

기존 전체 프로젝트를 덮어쓰려면 본인의 public/assets 이미지 파일을 먼저 백업하세요. 새 ZIP에는 실제 이미지가 포함되어 있지 않습니다.
